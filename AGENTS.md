# Instrucciones del proyecto FANGBOUND

- Implementar un sistema funcional por tarea.
- Mantener el código simple, modular y fácil de mantener.
- Usar ScriptableObjects para parámetros de diseño ajustables cuando corresponda.
- Mantener los estados temporales de ejecución en componentes.
- Usar el nuevo Input System.
- Explicar el trabajo en español y escribir nombres de código en inglés.
- No reescribir sistemas ajenos a la tarea.
- No introducir paquetes de pago.
- Explicar qué archivos se modifican.
- Documentar cómo probar cada entrega.
- No afirmar que algo funciona si no se ha comprobado.
- No realizar commits sin autorización.
